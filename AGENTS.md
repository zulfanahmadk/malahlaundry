# Branch kerja

- Repository ini hanya memakai branch `master` dan `qa-master`, baik lokal maupun di `origin`.
- Semua perubahan dan perbaikan repository ini dikerjakan pada `qa-master`.
- Simpan setiap perubahan melalui commit dan push ke `qa-master` terlebih dahulu. Perbarui `master` hanya jika pengguna secara eksplisit memintanya.
- Periksa branch dan status Git sebelum mengubah atau melakukan commit. Pertahankan pekerjaan yang sudah ada saat berpindah ke `qa-master`.
- Jangan membuat atau memakai branch tambahan kecuali pengguna secara eksplisit memintanya.
