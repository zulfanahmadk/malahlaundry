# Branch kerja

- Semua perubahan dan perbaikan repository ini dikerjakan pada `qa-master`.
- Periksa branch dan status Git sebelum mengubah atau melakukan commit. Pertahankan pekerjaan yang sudah ada saat berpindah ke `qa-master`.
- Jangan berpindah, melakukan commit, atau push ke branch lain kecuali pengguna secara eksplisit memintanya.
